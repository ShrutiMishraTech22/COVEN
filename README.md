# TrustGraph

Provenance-aware AI for digital evidence reasoning. See `docs/API_CONTRACT.md`
for the shared schema both frontend and backend build against.

## Quick start

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Visit `http://localhost:8000/docs` for interactive API docs (auto-generated by FastAPI).

### Frontend
```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm install tailwindcss @tailwindcss/vite reactflow recharts
npm run dev
```
Runs at `http://localhost:5173` by default.

### Database (once you're past mock data)
```bash
docker run --name trustgraph-db -e POSTGRES_PASSWORD=trustgraph -e POSTGRES_DB=trustgraph -p 5432:5432 -d postgres:16
```

## Task ownership (2-person split)

**Person A — Backend + Reasoning Engine**
- `backend/app/models`, `backend/app/schemas` — DB models + validation
- `backend/app/processors` — hashing, metadata extraction, normalization
- `backend/app/correlation` — cross-source event grouping
- `backend/app/contradiction` — rule engine (start with 3 rule types: location, temporal, identity)
- `backend/app/reliability` — reliability scoring formula
- `backend/app/hypotheses` — hypothesis scoring against templates

**Person B — Frontend + Data + Demo**
- `frontend/src/*` — all UI screens, evidence graph (React Flow), timeline, dashboard
- `data/synthetic` — the synthetic evidence dataset (build this FIRST, it's the
  backbone of the whole demo — see `data/synthetic/README.md`)
- Demo script + pitch deck
